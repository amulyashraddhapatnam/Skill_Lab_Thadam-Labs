# Thadam Labs - Using Agentic Coding
### **Problem Statement:**
Users often struggle to identify phishing, scam, and fake emails. Suspicious links, unknown senders, and misleading content can make emails difficult to trust. Important emails may also be wrongly moved to the spam folder, while repeated unwanted emails may not be properly flagged. This makes it difficult for users to identify threats and manage their inbox effectively.
### **Requirements:**
##### The system should:
- Identify safe, spam, suspicious, and potentially harmful emails.
- Highlight suspicious links, senders, and content.
- Detect repeated unwanted emails.
- Help identify important emails wrongly marked as spam.
- Show clear reasons and risk levels for flagged emails.
- Provide simple actions to manage flagged emails.
- Maintain a clean and user-friendly interface.

### Possible Solutions:
An AI-powered email threat detection platform that analyses emails, highlights potential risks, and presents the results through a simple and easy-to-understand interface. It will help users identify threats, recover important emails from spam, and manage unwanted emails more effectively.

### Implementation:
Using agentic coding with Google Antigravity, we developed the proposed solution into a fully functional web application. The project was generated, implemented, and tested through the agentic coding workflow, resulting in a working application that can be run locally through a localhost link and used to interact with the implemented features.
